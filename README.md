# Buscador de árboles

PWA para consultar árboles por especie, diámetro y número de placa, y llevar el consecutivo de árboles nuevos. Está preparada para instalarse desde el navegador del TDC6 y cargar sus páginas sin conexión después de la primera visita.

## Publicación

La aplicación se sirve desde GitHub Pages. Abra `https://adriandelgadotorres-sketch.github.io/buscador-arboles-campus/` con Chrome en el TDC6 y use la opción del navegador para instalarla o añadirla a la pantalla de inicio.

## Datos

Las marcas de árboles encontrados, las preferencias de tema y el control de consecutivos se guardan en el almacenamiento local del navegador. GitHub Pages distribuye las actualizaciones del sitio, pero esta versión no sincroniza los datos de campo entre dispositivos o personas.
